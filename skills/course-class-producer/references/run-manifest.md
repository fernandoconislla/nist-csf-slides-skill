## Criterios para declarar producción completa
- [ ] Todos los puntos explicados.
- [ ] Ningún texto visible carente de soporte narrativo.
- [ ] Todos los segmentos narrados asociados a slides.
- [ ] Gráficos fieles, pertinentes y consistentes.
- [ ] Deck Google Slides nativo verificado.
- [ ] Notas de presentador incorporadas **y leídas de vuelta**.
- [ ] Inspección visual integral sin defectos críticos.

Si falla una casilla, marcar entrega parcial o bloqueada; no confundir transcripción externa con notas embebidas. Audio reproducible es entrega separada.
