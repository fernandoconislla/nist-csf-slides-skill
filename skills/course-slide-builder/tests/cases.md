# Casos de regresión — Course Slide Builder

Casos definidos; **no se consideran ejecutados** hasta registrar evidencia real.

1. **Varios puntos, una slide:** tres puntos relacionados se explican en una unidad visual; se preserva narración completa y trazabilidad de los tres.
2. **Un punto, tres slides:** un proceso complejo necesita tres pasos; no forzar una slide por punto ni omitir fases.
3. **Texto no narrado:** un título introduce una condición técnica ausente en el guion; bloquear aprobación, corregir texto o narración mediante flujo autorizado.
4. **Recurso oficial NIST:** no recrear erróneamente el diagrama de funciones/tiers; verificar fuente y fidelidad.
5. **Slide saturada:** texto y diagrama no caben; distribuir en más slides manteniendo tamaños legibles.
6. **Notas inaccesibles:** conector no permite editar notas; entregar deck parcial/transcripción por slide, reportar que la narración **no** fue incorporada.
7. **Imagen estilo maestro:** conceptos distintos mantienen consistencia geométrica y cromática pero composiciones diferentes.
8. **Reutilizar plantilla:** crear una copia y no modificar el deck fuente.

Para cada prueba: entrada, operación efectiva, artefacto, evidencia estructural, render visual y estado `Ejecutada y conforme / Ejecutada con fallos / No ejecutada`.
